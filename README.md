# 形外 ATLAS

本地静态美学图鉴，可在完成图片授权检查后部署到 GitHub Pages。

- 首页：`index.html`
- 完整目录：`catalog.html`
- 收藏视图：`catalog.html?view=saved`
- 独立详情：`style.html?style=Cottagegoth`
- 1129 个英文正文记录：`data/entries/*.json`，进入详情页时按需加载
- 24 个重点中文内容与图库记录：`content.json` / `content.js`
- 本地图片：`images/`

全部 1129 个目录词条均有独立英文正文数据，抓取失败为 0；其中 2 个原站页面本身没有说明文字，页面会明确显示根据现有分类生成的基础记录。正文合计约 609 万英文字符。24 个重点词条保留中文内容与本地图库，其余词条使用本地目录封面，并按需加载最多 3 张原站远程图库图。全量远程图库共关联 3295 张图片，不计入 GitHub Pages 的发布体积。

## 来源与许可

文字源自 Aesthetics Wiki 条目及其贡献者，按站点声明的 CC BY-SA 使用，中文概览为编译摘要。页面保存了来源链接、版本编号和贡献者历史链接。英文正文以可读文本结构呈现，去除原站导航、广告、脚注标记和嵌入组件。

图片版权与文字许可分开；每张图片保留文件说明页链接，授权尚未逐项核实。本地导入不等于获得公开再发布图片的授权。

当前尚未发布到 GitHub Pages。无需服务器端应用或数据库，所有站内路径均为相对路径。

目录每页显示 48 个词条，筛选、排序与页码保存在 URL 中。进入详情页时同时记录目录地址和滚动位置，返回后可恢复此前浏览状态。收藏视图直接展示收藏结果，不显示搜索、筛选和排序控件。
